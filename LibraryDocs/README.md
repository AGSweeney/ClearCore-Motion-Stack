# LibraryDocs — ClearCore Motion Stack

Knowledge extraction package for ImplCache and agent retrieval.

Covers ClearCore firmware personalities (EtherNet/IP ClearLink-compat and EtherCAT I/O),
shared libraries (`libClearCore`, LwIP port, OpENer port, ClearLink bridge), host tools
(`EtherCATMaster`, `MotionBench`), and the draft LEAP protocol specification.

| Entry | Purpose |
|-------|---------|
| [INDEX.md](INDEX.md) | Retrieval routing table |
| [project/COMPONENT_INVENTORY.md](project/COMPONENT_INVENTORY.md) | Authoritative component IDs |
| [VALIDATION.md](VALIDATION.md) | Strict validation report |
| [CREATE_LIBRARYDOCS.md](CREATE_LIBRARYDOCS.md) | Skill pointer |

Standard: `create-librarydocs` **2.1.0**.
